# Crypto Sniper Trading Skill

AI 加密货币交易分析 Skill，基于 200 USDT 超小资金狙击手模式。

## 用户交易准则

- **本金**: 200 USDT
- **策略**: 极低频、极高置信度
- **仓位**: 20%-50% 高比例开仓
- **止损**: 2%
- **止盈**: 4%
- **最小证据数**: 2 条

## 三重共振条件（必须同时满足）

1. **4H 宏观趋势确认**
   - EMA20 > EMA50 → 多头
   - EMA20 < EMA50 → 空头

2. **极端 OI/资金费率偏离**
   - 资金费率 > 0.05% + ΔOI > 5% → 做空信号
   - 资金费率 < -0.05% + ΔOI > 5% → 做多信号

3. **15m 精准放量**
   - 成交量 >= 2 倍平均
   - 价格突破 > 0.5%

## 使用方式

```
分析 BTC/USDT 当前市场
获取 ETH/USDT 交易信号
建议是否买入 BTC
```

## 功能

1. **实时市场分析** - 获取多时间框架数据
2. **技术指标计算** - RSI, MACD, EMA, ATR, 布林带
3. **K线形态识别** - 锤子线、吞没、十字星等
4. **宏观数据分析** - 资金费率、OI、多空比
5. **三重共振检测** - 验证是否满足交易条件
6. **AI 交易建议** - 基于证据链给出决策

## 安全规则

- 必须满足三重共振才能交易
- 至少需要 2 条证据
- 有 veto_flag 时禁止交易
- 止损必须 < 2%
- 止盈目标 >= 4%
