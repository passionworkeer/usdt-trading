## 🎯 核心架构

```
MTF 三重共振触发
        ↓
   宏观禁令检查（每小时更新）
        ↓
   AI 微观审批（3-5秒）
        ↓
   锁定触发价格
        ↓
   AI 思考...
        ↓
   滑点检查（0.5%阈值，5秒超时）
        ↓
   执行交易 / 撤销
```

## 🚀 使用方法

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

复制 `.env.example` 到 `.env`，填入：

```bash
# 必需
ANTHROPIC_API_KEY=your_key_here
ENABLE_AI_AGENT=true

# 可选（没有也能运行）
TWITTER_BEARER_TOKEN=your_token_here
```

### 3. 运行

```bash
python scripts/sniper_trader.py
```

## 📊 功能特性

### ✅ 已实现

1. **自然语言数据翻译器**
   - 资金费率解读
   - 订单簿失衡解读
   - 成交量分析
   - EMA 距离解读

2. **外部情报嗅探器**
   - Twitter API v2 集成（可选）
   - CoinDesk RSS 新闻抓取
   - 情绪分析（关键词方法）

3. **宏观大局观**
   - 每小时生成
   - 市场情绪判断（panic/neutral/euphoric）
   - 交易禁令（禁止做多/做空）

4. **微观审批**
   - 3-5 秒 AI 思考
   - 结合技术面 + 宏观面
   - 置信度阈值（0.6）

5. **滑点硬拦截**
   - 0.5% 滑点阈值
   - 5 秒超时
   - 物理铁律：无法绕过

### 🔧 可选依赖

- **Twitter API**: 没有也能运行，只是跳过情绪分析
- **Claude API**: 必需，否则 AI Agent 不可用
